# AI Usage

AI assistance was used during the development of this project for:

- understanding the challenge requirements;
- exploring suitable machine-learning approaches;
- helping with Python coding and debugging;
- reviewing validation results;
- organizing project documentation.

The final implementation decisions, testing, and validation were done by me.

## One Thing AI Got Wrong

During development, an early version of the comparison script produced incorrect negative counts and proxy costs because a boolean condition was handled incorrectly.

I noticed that the output was impossible, checked the calculation, fixed the logic, and reran the comparison successfully.

This was a reminder to verify AI-generated suggestions and code through actual testing.
